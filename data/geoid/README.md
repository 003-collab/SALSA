# Geoid Data

Geoid data for use in other SPP projects

## Files

The file egm2008_2.5m.und is a renamed version of Und_min2.5x2.5_egm2008_isw=82_WGS84_TideFree_SE
which was obtained from NGA's web site.

The file egm1996_2.5m.und is a renamed version of N_2p5m_egm96.bin which was provided by Jim Friederich
to match the format of our 2.5 minute EGM 08 file.

The file g2018u0.asc was downloaded from the NGS website, and contains the heights for the Geoid18 specification.  The grid has a spacing of 1 arcminute, but only contains data for CONUS in the bounds (24N-58N), (130W-60W)

The file g2012bu0.asc was also downloaded from the NGS website, and contains heights for the Geoid2012b model.  This file is in the same format as g2018u0.asc.
