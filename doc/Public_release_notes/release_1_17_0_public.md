# SALSA 1.17.0 Release Notes

August 13, 2024,

SALSA 1.17.0 adds an important new feature (undo/redo), improves existing features, and fixes several bugs in the
1.16.1 and earlier releases.

Approved for public release by the National Geospatial-Intelligence Agency. 

## New Developments

* Undo/Redo

  * A new feature, undo/redo, is introduced.
  * Undo/redo applies to any action a user can take that could be captured in a .lsa file:
    1. Inserting new records.
    1. Removing records.
    1. Changing a record's value via the record editor.
    1. File imports and conversions.
  * For more information on the scope of undo/redo, refer to the design document attached in the same email.

* Multiple entries in the filter box:

  * The Find/Filter widget (ctrl+F) now supports multiple entries in the filter and find boxes.

* Export Improvements:

  * Users can now export point confidence and reliability rectangle values.
  * DXYZ covariances are now displayed in ENU in the record editor, and DXYZ raw residuals in ENU can be exported
  to a csv file.

## Known Issues

* Exporting the map as a JPEG or JPG fails on some systems. If an export failure occurs we recommend trying to
export the map as a .png file instead.
* The user can hide the map widgets (e.g. home button) and has no way to restore them aside from restarting SALSA.

## Downloading and Installing

The SALSA msi installer is being rebaselined to SALSA version 1.17.0, i.e., there is no patch file (*.msp) available
for SALSA 1.16.1.
